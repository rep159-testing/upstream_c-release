# upstream_c

Top of the three-package chain in the `upstream` distribution of the
[REP 159](https://github.com/openrobotics/reps/pull/32) test harness:
`upstream_a` ◄ `upstream_b` ◄ `upstream_c`. Labels the summary `upstream_b`
gives. `srcext` rebuilds this chain with `source_rebuild`. Plain CMake
package, no ROS dependency.

Index and distribution files: https://github.com/rep159-testing/rep159-rosdistro
